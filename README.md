# ☕ Me_-_Java

Welcome to my **Java Learning Journey** repository! 🚀  
This repository contains my practice programs, exercise solutions, and topic-wise code implementations as I learn core Java concepts from scratch.

---

## 📌 Repository Overview

Here is a quick overview of the topics covered in this repository:

| File Name | Topic / Description |
| :--- | :--- |
| `firstclass.java` | Introductory Java program, basic syntax, and printing outputs. |
| `takinginput.java` | Reading input from the user using `Scanner`. |
| `secondclass.java` | Basic operations and core foundational practice. |
| `conditional.java` | Control flow using `if`, `else if`, `else`, and `switch` statements. |
| `Loops.java` | Iteration mechanisms (`for`, `while`, and `do-while` loops). |
| `Patterns.java` | Pattern-printing problems using nested loops. |
| `Questions.java` | Practice coding questions covering various concepts. |
| `Homework.java` | Daily homework tasks and assignment problems. |

* An IDE or Text Editor of your choice (VS Code, IntelliJ IDEA, Eclipse, etc.)
